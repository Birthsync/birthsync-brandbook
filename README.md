### **Слоган**

Существует несколько вариаций слоганов:

1.) Меньше суеты — больше радости.
2.а.) Знаем вкусы ваших друзей.
2.б.) Знаем вкусы ваших близких.
3.) Сохраняйте желания. Исполняйте вовремя.
4.) Ваш персональный помощник по подаркам.

Итоговым же является один единственный — «удивляй» на все маркетинговые решения данного продукта. 
### **Торговое предложение**

Мы делаем продукт для людей и про людей, наши услуги работают не только с вами как с человеком, с вашей памятью, но и с вашими близкими. Наш бренд $-$ это результат гуманизации нашей фирмы, наше лого $-$ это наше лицо, наш товарный знак $-$ это наш паспорт.
